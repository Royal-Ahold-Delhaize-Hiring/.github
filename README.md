# Royal Ahold Delhaize Hiring

The public hiring entry point for platforms across Ahold Delhaize.

**Candidates:** start with the [organization profile](profile/README.md) and follow
the link to the platform you are interviewing with.

## For platform owners

Each platform owns its candidate guide. Technology stacks, interview formats,
assessment policies and preparation requirements belong in that guide, not on the
shared landing page.

| AH RBP - Retail Business Platform | [AH RBP](platforms/ah-rbp.md) |
| AH STP - Store Tech Platform | [AH STP](platforms/ah-stp.md) |

### Update or add a platform

1. Edit your platform's Markdown guide. For a new platform, copy
   [the platform template](templates/platform.md) into `platforms/` using a stable,
   lowercase filename.
2. Fill in confirmed details and remove the unpublished notice when the guide is
   ready. Do not copy another platform's requirements unless they also apply to
   yours.
3. Add new platforms to the directory in `profile/README.md` and the table above.
   The initial directory is not an exhaustive list of banners or departments.
4. Open a pull request and involve the people responsible for that platform's
   hiring process.

Keep the landing page neutral. Do not include candidate information, assessment
solutions, interview feedback or private repository links anywhere in this public
repository.

See [the documentation](docs/index.md) for the content model and publishing
details.
