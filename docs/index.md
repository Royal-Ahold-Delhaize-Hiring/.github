# Hiring organization profile

This repository hosts the public GitHub profile for
[Royal Ahold Delhaize Hiring](https://github.com/Royal-Ahold-Delhaize-Hiring).
It provides a shared entry point, not a shared technology stack or hiring process.

## Content model

- `profile/README.md` is the organization landing page.
- `platforms/` contains one candidate-facing Markdown guide per platform.
- `templates/platform.md` provides a starting point for platform owners.

Platforms maintain their own introductions, technology stacks, hiring processes,
preparation requirements and contact details. Unconfirmed details must remain
explicitly marked as unpublished rather than inferred from another platform.

## Public content

Everything in this repository is public. Do not include candidate names, personal
information, interview feedback, assessment answers, private repository links or
credentials. Candidate-specific work belongs in separately managed private
repositories.

## Publishing

GitHub displays `profile/README.md` on the organization's public overview when it
is present on the default branch of the public `.github` repository. There is no
application, build step or hosting service.

Use absolute GitHub URLs for platform links on the organization landing page so
they work both on the organization overview and inside the repository.

## Initial platform guides

AH CTP, AH RBP, AH STP and AH EEP have explicit unpublished notices and sections
for their owners to complete. GET's guide was adapted from the existing
[GET organization profile](https://github.com/gall-etos-tech/.github/blob/main/profile/README.md).
Its technology stack, interview timing and preparation requirements are scoped to
GET only. The circular cyberpunk logo is the existing public avatar of the
[GET organization](https://github.com/gall-etos-tech), stored locally as
`platforms/media/get-logo.png`.

The old profile's claim that only GET interviewers can see a candidate repository
is not repeated: private repository visibility alone does not establish that
restriction. Actual access depends on organization and repository permissions.

This publication does not move candidate repositories, grant access, change
organization settings or establish a group-wide assessment policy.
